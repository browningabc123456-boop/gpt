## 本包内容

ZIP 根目录直接是 `index.html`；`assets/game.js` 为经典外置脚本，样式和许可证也在包内。只包含运行所需的四个静态文件，没有源码目录、node_modules、构建配置、source map 或外部资源。六个场景在单页内切换，不包含已删除的船屋、室内小房间、节日和“小惊喜”面板。

小红书版独立适配：保存截图通过用户点击调用容器的临时文件和相册接口，未保留浏览器下载或长按保存提示；9.46+ 且接口可用时使用容器存档，其他环境在可用时回退到本机浏览器存储，失败会显示提示。存档按小工具隔离，和网页版不跨端同步。音乐在用户首次操作后由设备允许播放。

代码构建目标为 ES2017 / Chrome 61，给实际使用的新 API 和布局提供回退。**Chrome 61 / Android 8.1 的实际 JS、CSS 兼容性未实测；Android / iOS 真机性能未实测。** 三维绘制限制像素、DPR、draw call 和三角形预算，持续低性能时只逐级降低分辨率和动画频率，保留完整三维搭建；只有图形能力缺失或 context 反复丢失时才切换可保存作品的轻量模式。轻量模式保留基础造景，不承诺完整三维特效。
