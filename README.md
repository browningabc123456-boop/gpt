# 团子的小世界 · 3D 仓鼠越狱

真正的 3D 搭建冒险：可以旋转视角、搬动和堆叠笼子里的物件，亲自操控一只立体仓鼠走路、跳跃和攀爬。仓鼠必须越过笼子边界并落到外面，才会解锁下一关。

六个主题：阳光木屋、饼干工坊、雨林温室、海边灯塔、月光观测站、云端玩具阁楼。每关有独立的配色、布置、主题摆件和高台高度。所有场景与角色均为 Three.js 网格模型；刚体碰撞、重力、堆叠使用 cannon-es。没有把平面角色图片当成立体模型，也不需要运行时联网获取模型或贴图。

## 开发

需要 Node.js 22+（推荐 24）、npm，以及支持 WebGL 2 的浏览器。

```sh
cd /workspace/gpt
npm ci
npm run dev
```

默认监听 0.0.0.0:3000，`PORT` 可更改端口。源代码版本通过 HTTP 打开；直接双击源代码的 HTML 不会加载依赖。

## 操作

- **视角**：拖动空白处旋转，滚轮缩放，右键拖动平移。手机单指旋转、双指缩放。画面右上方有归位、俯视、跟随按钮。
- **自由搭建**：拖动物件，移动到其他物件上方自动堆放。放开后应用真实重力；不稳的结构可能倾倒。选中物件后，在工作台转向、倾斜或恢复原位。`R` 转向。
- **操控团子**：`WASD` / 方向键移动，`空格` 跳跃；靠近并面向矮台阶按 `E` 攀上或攀下。无法直接爬上过高的墙，需要搭台阶或跳跃。`B` 切换搭建/操控。手机使用摇杆与跳跃、攀爬按钮。
- **通关**：右侧高处有出口和外部安全垫，也可自己搭路翻过其他围栏。停在笼内高台不算通关。离开笼子并落地后开启下一座主题笼子。
- **回窝**：仅重置仓鼠，保留搭建；重新布置则重置当前笼子的物件。通关与布局保存在当前浏览器，不跨设备同步。

九件可搬物件包括大小木箱、积木、长/宽木板、空心纸筒、矮凳、实体斜坡与软垫。纸筒具备空心碰撞结构，仓鼠可以穿过内部；斜坡使用楔形碰撞体。

## 检查与构建

```sh
npm test
npm run build
```

26 项物理测试包括六座笼子的完整通关路线（只摆放已有物件，通过连续移动、攀爬与跳跃完成，不传送仓鼠），以及堆叠、悬空下落、墙壁碰撞、纸筒穿行、跳跃限制、逃出判定、逐关解锁和跌落回窝。

构建产物 `dist/index.html`（也会复制为仓库根目录的 `hamster-3d.html`，便于直接从 GitHub 下载）包含全部代码、物理引擎和样式，纹理与模型由代码生成，没有外部资源请求。可用支持 WebGL 的浏览器打开，或部署到任意静态网站服务；也支持子目录部署。嵌入式预览若禁用 WebGL，需要在支持 WebGL 的独立浏览器页面中运行。

## 文件

- `src/levels3d.js`：主题、场景规格、工具、进度解锁规则。
- `src/physics3d.js`：真实刚体、堆叠、移动、跳跃、攀爬与逃出判定。
- `src/hamster3d.js`：立体仓鼠、细绒毛网格、步态与攀爬动画。
- `src/world3d.js`：场景、真实材质、光照阴影、相机和物品模型。
- `src/game3d.js`：操作、触屏、界面、存档与关卡流程。
- `src/game.css`：响应式界面。
- `build.mjs`：用 esbuild 生成独立 HTML。
- `server.mjs`：开发服务器。

## GitHub Pages

`.github/workflows/pages.yml` 会安装锁定依赖、测试、构建并发布 `dist/`。需要仓库拥有者先在 Settings → Pages → Source 选择 GitHub Actions；若先前运行失败，可在 Actions 的 Publish hamster game 中重新运行。成功发布的工作流会返回网站地址。上传代码不代表网页已经上线，云环境的发布与 GitHub Pages 的发布也是两件不同的事。
