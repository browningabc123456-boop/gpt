# 仓鼠施工队 · 小小越狱计划

一个可以在浏览器玩的温馨搭建解谜游戏。使用木板、纸筒和弹簧垫，为小仓鼠搭一条前往点心小屋的路线。立体玩具风场景、原创仓鼠素材、六个由浅入深的关卡，无广告、无账号要求。

## 本地启动

需要 Node.js 20 或更新版本，无第三方运行依赖，无需 `npm install`。

```sh
cd /workspace/gpt
npm run dev
```

服务器默认监听 3000 端口，可通过 `PORT` 环境变量指定端口。浏览器打开运行机器的 3000 端口即可游玩。请通过 HTTP 服务打开，不要直接双击 HTML 文件（浏览器会限制 ES 模块）。

## 怎么玩

1. 从工具箱拖入材料，或点击材料后点击场景放置。
2. 选中已放置的材料，在右侧工作台调整角度；弹簧还能调整力度，虚线圆点显示初段弹跳方向。
3. 木板、纸筒两端都需要连接平台或已稳固的材料；弹簧底部需要支撑。绿色端点代表稳固，橙色虚线代表悬空。放置时会自动轻微吸附到平台高度。
4. 点击“出发试跑”，小仓鼠自动向右走。可以暂停并返回搭建，反复修改，没有次数惩罚。
5. 瓜子是额外挑战，抵达右侧小屋就过关。低顶下仓鼠会压低身子；跳跃中不能穿墙。第五关起，小门必须有平放的木板或纸筒持续压住按钮才能开启。

所有关卡从一开始都可以在冒险地图中选择，三种材料每关都可用，但数量有限。搭建方案、最佳瓜子数与通关记录保存在当前浏览器的本地存储中，清除网站数据会丢失记录。

快捷键：空格试跑/暂停；Delete 或 Backspace 收回选中材料；Ctrl/⌘ + Z 撤销；Esc 取消拿取。支持鼠标和触屏，移动端可点击材料后点击场景放置。音效默认关闭，可手动开启。

## 验证

```sh
npm test
```

测试包含六关在材料限额内通关并收齐瓜子、真实坠落、悬空支撑、机关压力、低顶碰撞、弹簧力度、试跑重置和固定步长一致性。物理模拟以 120Hz 固定步长运行，画面用 Canvas 渲染。

## 文件

- `src/engine.js`：关卡、材料支撑、压力机关和物理模拟。
- `src/render.js`：场景、角色、材质、动画和粒子。
- `src/app.js`：操作、界面、音效、存档和流程。
- `src/style.css`：响应式界面。
- `assets/hamster.png`：为本项目生成的透明背景角色素材，离线随项目提供。
- `server.mjs`：零依赖静态开发服务器。

## 生成可直接打开的版本

```sh
npm run build
```

生成 `dist/index.html`，这是一个包含全部代码、样式和角色图片的独立文件。下载后用浏览器打开就能玩，不需要服务器或联网。它也可以直接部署到静态网站服务，支持子目录部署。

源代码版本也可以部署到支持静态网站的服务；发布 `index.html`、`src/` 和 `assets/` 即可。源代码版本的资源路径以网站根目录为基准。

## 发布到 GitHub Pages

仓库内已提供 `.github/workflows/pages.yml`。代码提交到 GitHub 的 `main` 分支后，在 GitHub 仓库的 Settings → Pages → Build and deployment 中，将 Source 设为 GitHub Actions。若首次运行发生在启用 Pages 之前，在 Actions 中重新运行 Publish hamster game 即可。

发布流程会先执行规则测试、生成独立网页，再部署 `dist/`。部署成功后可在 Actions 任务的 github-pages 环境中获得独立访问地址。此操作会公开发布游戏，需要仓库拥有者授权；准备好配置不代表已经发布。
