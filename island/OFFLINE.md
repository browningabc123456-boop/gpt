# 孤岛绘境 · 离线网页包

本包是网页游戏，不是 APK，也不是 GitHub 页面里的代码预览。
引擎、字体、图片、纸材和音乐均已内嵌，运行时无需访问原试玩网站或 CDN。

## 手机

1. 下载 island-sketchbook-web.zip，使用手机文件管理器解压。
2. 找到解压后的 index.html，选择「用浏览器打开」，优先使用支持 WebGL 2 的系统浏览器。
3. 如果手机只展示源码、只预览文件，或不允许浏览器打开本地 HTML，则当前打开方式不支持运行。请使用电脑，或把本包部署到可访问的静态网页托管后再用手机打开。

没有验证所有 Android / iOS 文件管理器的打开行为，不能保证每款手机都可以直接运行本地文件。无需安装来源不明的 HTML 查看器。

## 电脑

解压后用 Chrome / Edge 打开 index.html。若浏览器限制本地文件，进入解压目录运行：

    python -m http.server 8080 --bind 127.0.0.1

然后在同一台电脑访问 http://127.0.0.1:8080/ 。这不是提供给手机的互联网地址。

## 保存

作品保存在当前浏览器，文件地址或浏览器变化可能导致无法读取原存档。换设备、移动文件或清理浏览器前，请在「我的小岛」中导出 JSON 存档。原试玩网站的作品不会自动复制到离线版，可导出后再导入。

## 操作

点按 / 滑动绘制；双指缩放、平移和旋转。侧栏可收起，71 种笔刷；「随机建一个」快速生成完整景观。音乐需主动点击开启。风景卡需点击保存，浏览器会发起图片下载。
