# 孤岛绘境 · 第七版

[小红书上传候选包 v6](https://github.com/browningabc123456-boop/gpt/raw/refs/heads/main/releases/island-sketchbook-xhs-v7.zip) · [离线网页版](https://github.com/browningabc123456-boop/gpt/raw/refs/heads/main/releases/island-sketchbook-web.zip) · [源码](https://github.com/browningabc123456-boop/gpt/tree/main/island)

## 本版变化

- 手机笔刷移至底部横向抽屉，画布、笔刷、底栏分占各自布局行。支持收起 / 展开、横滑选择，尺寸与疏密并排显示；收放保持画面中景物尺寸。
- 移除右侧缩放 / 旋转 / 俯仰控制区和悬浮视角文字，底栏「调整」改为「方向」。
- 双指捏合缩放、同向移动平移、扭转旋转；只有双指都从主岛边界外的海面开始、以平行纵向动作移动时，才进入俯仰。岛内上下拖动保持平移；轻微抖动、捏合、扭转不会误触俯仰。多指操作撤销首指未完成的笔迹。
- 单指在岛外海面拖动可直接平移；岛内仍按当前笔刷绘制。物件朝向通过「方向」调整，和镜头手势分开。

## 延续内容

- 提高纸材输出对比，重新分配主光和环境补光，草地、水面加深饱和度，保留纸纤维、折面、厚地层和接触投影。白天没有全景雾或天气遮罩。
- 密度范围扩展为 15%–400%，同时改变植物数量和沿笔迹生成间距；房屋保持单次一座，水域、地形、桥栅保持连续。
- 12 种主题、10 类构图：河谷、潟湖、错落池塘、交叉水街、对称庭园、梯田、花田、村落、营地和沿海细节。主题选取不同构图、镜像、旋转、建筑聚落、树丛、田垄与装饰。种子可重现，每次生成可整次撤销。
- 保存分为工作草稿和手动作品存档，最多 40 个、受设备空间限制。进入时选择继续编辑、已有存档或新建。支持命名、覆盖、另存为、缩略图预览和删除；删除作品不清空工作草稿。切换未保存画面前提供保存 / 放弃 / 取消。
- 旧 version 1 / 3 的岛屿迁移为 version 4 存档库，原生地形与拓建范围保留。旧天气移除，原昼夜保留；旧流星移除。迁移前保留原始备份键。
- 只保留白天和夜晚；取消天气入口及运行时天气粒子。移除流星笔刷，薄雾改为柔和、羽化的横向云雾，不投影，可叠涂。
- 删除右侧地图、画笔说明、工具箱标题和数量、页脚宣传文案、随机面板说明。去掉岛屿相册，不再收藏图片。
- 「保存」面板支持保存作品存档或把带纸质装裱的图片保存到系统相册（浏览器版发起 JPEG 下载）。新图不会自动截图或收藏。
- 双指同向移动平移，捏合缩放，顺时针扭转让岛屿顺时针转动；岛外双指纵向拖动俯仰，底栏「方向」调整物件朝向。

## 操作和数据

70 种可选笔刷。花草、树木、水域、石头、构筑、装饰、地形、人和动物保留；新岛没有预放景物。初始大岛 3600 × 2600，免费拓建四次，面积上限为初始的 3.24 倍。单岛笔迹上限 12000，30 步撤销。人物动物自主活动。

沿用存储键 `island-sketchbook-v1`，内部数据升级为 version 4。自动暂存不等于手动存档；手动保存时创建与工作草稿隔离的快照。备份 / 恢复通过文本完成，不读取剪贴板，不使用平台禁止的 JSON 文件选择或 Blob 下载。备份含作品存档和工作草稿，不含旧版相册。

卸载、清除应用数据或更换设备可能丢失本地数据，不自动跨设备同步。旧相册数据不再读取或新增，不在升级时自动清除；如占用平台缓存配额，需要用户自行备份后通过平台清理。

## 开发

仓库根目录：

    npm ci
    npm run test:island
    npm run build:island
    npm run build:island:xhs
    npm run test:island:xhs

`island.html` 和 `island/dist/index.html` 为单文件网页版。上传版独立输出到 `island-xhs-dist`，经典外置脚本、包内图片 / 字体、Chrome 61 / ES2017 编译目标。详细平台边界见 [xhs/README.md](xhs/README.md)。

40 项规则 / 存档 / 布局 / 手势测试和 7 项平台桥接 / 打包测试。本地 Chromium 使用严格 CSP 和模拟平台接口检查手机布局、手动存档的新建 / 保存 / 覆盖 / 删除 / 重开、存储失败回滚、图片保存和旋转方向。真实小红书 WebView 的帧率、相册授权和平台审核尚需在上传页预览验证。

所有引擎、图片、字体、纸材、模型和原创合成音乐均在包内，无运行时 CDN。Three.js 与字体许可保留在网页、源码和上传包中。GPU 实例复用、地形空间索引与输入帧合并保留，密集场景仍需目标手机性能验证。
