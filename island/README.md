# 孤岛绘境 · 剪纸造景工具箱（第五版）

公开试玩链接：https://island-sketchbook-q7m.browningabc123456.chatgpt.site （部分网络可能被托管平台拦截）。

GitHub 离线下载：[网页包](https://github.com/browningabc123456-boop/gpt/raw/refs/heads/main/releases/island-sketchbook-web.zip) · [源码包](https://github.com/browningabc123456-boop/gpt/raw/refs/heads/main/releases/island-sketchbook-source.zip)。使用方法见 [离线打开说明](OFFLINE.md)。

真实 Three.js 三维场景，纸雕层叠岛屿、切纸树冠、折纸花瓣、立体纸房屋、粗糙纸边 UI 与暖光。所有引擎、标题、字体、材质和音乐均包含在本地包中，无运行时 CDN、外部图片、字体或音频请求。

## 第五版：清晰的立体纸雕与连续建造

- 晴日和阴雨去掉全景雾洗，雾仅由用户选择天气或薄雾笔刷出现；主光与环境补光重新分配，增加折面明暗和接触投影，保留明亮的纸色。
- 树冠有折痕、纸层切边，屋檐叠纸与门框底座加厚；人物动物改为圆润切纸轮廓、厚纸折面、分层耳朵、眼睛高光、爪子和毛色斑纹。
- 静态景物采用按模型复用的 GPU 实例。连续绘制只新增或更新实例矩阵，擦除回收位置，已有模型和动物不重建；地形、水面也复用网格与贴图。
- 输入在动画帧中合并；小地图降低更新频率，画笔优先；投影独立刷新。新增地形空间索引，并保留陡坡的精确拾取回退。
- 同一 680 物件场景、16 次长划更新的本机 Chromium CPU 测试：平均场景同步约 264 毫秒降至约 1 毫秒。这个数值不代表真实手机整帧帧率。

## 日光纸材校准

使用不带灰绿色的奶油白环境补光，白天调整为保留纸色的输出；阴影强度与柔化半径独立控制。房屋使用奶油色墙纸与原木纸板两套材质，草地、水域与模型都有合适比例的细纸纤维，消除过密纹理缩小时的灰暗。白天、阴雨、夜晚均分别检查，缩放、相册与素材图标使用一致的纸材。

## 第四版升级

- 提亮纸材，调整白天暖光与草地水色；厚纸雕地层加厚，纸片保留切边与纤维，修复地面自身投影的条纹。
- “随机建一个”支持六种主题，带花田、树林、三处建筑、溪流、木桥、小径、灯饰与访客；主题内的布局有种子随机变化，一次撤销可恢复原岛。新岛仍为空白。
- 人物与动物改为有厚度的切纸轮廓、折面和纸边；四肢、翅膀、尾巴独立运动。角色自主散步和停留，避开水域、房屋和陡坡，鸭子可游泳。漫游状态是实时视觉状态，不生成后台任务。
- 景物生长用 GPU 逐物件弹性动画，随机场景有分批长出的节奏；减少动态效果偏好下直接显示完整景物。
- 只保留白天和夜晚。夜晚有蓝色月光、切纸月亮与星点、暖窗灯笼和局部暖光，保留纸张本来的颜色。
- 静态纸片按材质合批，角色保留活动关节并用顶点色合并细小纸片，减少绘制调用。

## 延续的功能

1. 强化切纸造型：树冠与纸云采用有厚度的纸片轮廓，花瓣、枫叶、屋檐与树木有折面和接触阴影，岛缘保留纸纤维和十层切面。
2. 侧栏可收起，并记住设备上的收放偏好。
3. 71 种独立笔刷，按花卉水草、树木灌木、岩石矿物、房屋构筑、生活装饰、地形水域、居民动物、氛围光影分组。
4. 光斑为光束和地面碎光；萤火虫为暖黄脉动的飞行微光；流星为天空中的星头和细长尾迹。
5. 薄雾没有投影，单次约 3.5% 不透明度，叠涂逐步加深。
6. 大小改变覆盖范围和物件尺寸，疏密改变生成数量与间隔。房屋保持每次一座，水体/地形保持连续涂抹，这些工具会明确禁用不适用的疏密滑杆。
7. 原创慢拍钢琴式旋律与轻柔和弦，本地 WebAudio 合成。点击音符可播放、暂停及调音量；后台暂停。
8. 晴日、阴天、晨雾、细雨、小雪五种天气，分别改变光照、云雾、雨线、地面涟漪与雪片。白天与夜晚独立选择。
9. 双指移动平移、捏合缩放、扭转旋转。电脑右键拖动可旋转和俯仰，右侧也有旋转、俯仰和归位按钮。
10. 房屋按住拖动时确定朝向，点击使用默认方向；建好后点「调整」选中房屋、装饰或居民，通过角度条或左右按钮转向。可撤销。
11. 原生旧水域和新笔刷水域使用同一张水面材质、同一填色与岸线逻辑。
12. 新玩家、新岛均从空白地面开始，无预放植物、房屋、动物、水域或高地。旧玩家已经编辑的作品保留；未改动过的旧示范布局移除前会保留升级备份。
13. 免费拓建四次，边长从 1.0 到 1.8 倍，面积最多 3.24 倍。景物保持原位，拓建可撤销。
14. 抬高、挖低、圆丘、台地、平整改变真实高度；沙地、草地、小径、湿地、碎石地改变纸面材质。可反复叠涂，地势高低有上限；抹除地形笔迹可还原。
15. 居民与动物笔刷包括旅人、儿童、猫、狗、兔、鹿、绵羊、野鸭、小鸟、蝴蝶。角色可旋转并会自主漫游，投放位置作为活动中心，不包含人物操控或养成任务。
16. 取消自动拍照。用户手动生成风景卡预览，可填写心情，再主动保存到本地并收入岛屿相册。卡片含纸质装裱、标题、岛名、日期与印章。

## 开发

仓库根目录：

```sh
npm ci
npm run test:island
npm run build:island
npm run dev
```

打开 `/island.html`。`island/dist/index.html` 与根目录 `island.html` 是独立单文件产物；需要支持 WebGL 2 的浏览器，推荐 HTTP 预览。源码包解压后可独立 `npm install`、`npm test`、`npm run build`。

## 操作与保存

单指点按/滑动造景，侧栏可折叠；「漫游」让单指拖动视野，「调整」让点选物件进入转向面板。鼠标滚轮缩放、右键拖动视角，Shift 拖动平移。快捷键 B 画笔、E 擦除、R 转动选中物件、Q/W 转动视角、空格漫游、Ctrl/⌘ Z 撤销。

三座独立小岛；沿用存储键 `island-sketchbook-v1`，数据升级为 version 3。旧作品坐标不变，旧版原生地形随作品保留，新岛没有原生景物。升级前备份可在「我的小岛」中导出。存档支持 JSON 导入导出，不自动跨设备同步。

30 步撤销/重做涵盖造景、擦除、地形、拓建、转向和清空。重新留白会移除当前岛地形与景物，保留拓建面积，不影响其他岛与相册。单岛最多 12000 个笔迹物件，初始坐标画布 3600 × 2600；此最大容量仍需目标设备性能实测。

卡片预览不自动收藏。点击保存后向浏览器发起 JPEG 本地下载，或在支持的宿主中调用系统相册；然后保存到岛屿相册。浏览器只能确认发起下载，无法保证用户最终保留文件。相册最多 16 张，存储不足时明确提示。旧版自动照片仍可查看，但不会再产生自动照片。

## 检查

23 项规则测试覆盖空白起始、71种目录、独立品种、尺寸和疏密、建筑拖动朝向与转向历史、水生限制与水体连通、真实地形高低、拓建边界与上限、雾气叠涂、桥栅衔接、擦除恢复、双指取消及多岛隔离。

Chromium 浏览器另外验证手机布局、侧栏收放、真实指针建造方向、建后转向撤销、双指旋转不留下笔迹、拓建撤销、手动卡片在保存前不入相册、实际 JPEG 下载、重新打开后的作品与相册恢复，以及全部 71 种模型缩略图。

## 发布与平台适配

`releases/island-sketchbook-web.zip` 为入口 `index.html` 的静态 H5 包；`releases/island-sketchbook-source.zip` 含源码、字体与许可。

原 Sites 链接已开放免登录访问，但不能保证所有网络可以访问。小红书接口继续以可选的 `window.xhs.miniTool` 检测接入存档和相册，未验证当前官方 SDK 或小红书真机兼容性；浏览器测试不代表小红书已提审或已上线。正式平台发布还需核验 WebGL、触控、SDK、存储及包体限制、系统相册权限和 iOS/Android 真机表现。

## 文件

- `core.js`：71种笔刷目录、生成规则、大小疏密、地形采样、拓建、转向和历史。
- `paper-world.js`：实时三维场景、高度网格、统一水面、纸雕材质、氛围与相机。
- `paper-library.js`：花树岩石、房屋、装饰、人和动物的剪纸模型。
- `music.js`：原创钢琴式旋律与和弦合成。
- `game.js`：触控、选择转向、界面、风景卡、存档与可选宿主适配。
- `tests.mjs` / `build.mjs`：验证与独立网页、ZIP 构建。
- `assets/legacy-starter.json`：仅用于识别未修改的旧示范布局，不作为新岛起始内容。
- `assets/THREE-LICENSE.txt`、`assets/FONT-LICENSE.txt`：引擎与 Noto 字体许可。发布 HTML 也内嵌许可文本。
