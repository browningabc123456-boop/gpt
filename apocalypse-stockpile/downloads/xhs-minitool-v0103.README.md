# v0.10.3 五项反馈修复

共享源码位于 src/；网页与小工具使用同一套无硬切音效、手势和物品绘制逻辑。小工具继续使用已安装的官方 1.8.0 skill，在线文档本次仍返回 HTTP403，按允许的随包基线保守适配；不声称完成在线契约核验。

1. 连续放置声：废除网页 Audio 元素的 pause/currentTime 硬重置；共享 PCM 缓冲播放，6ms起音、25ms尾音、12ms旧声音释放，85ms密集触发节流。袋装拟音降至1400Hz低通，保持袋装0.60、瓶装0.48上限参数。离线混音75次触发，峰值约0.248，削波0、瞬间停止0；没有手机扬声器验听数据。
2. 明亮仓库：提高日间环境补光、填充光和曝光；默认背景、墙面、地板调整为明亮暖色，保留已有场景选择与夜间设置。
3. 双指方向：相机顺逆时针与手指扭转方向一致；平移和张开放大保持原操作，家具直接旋转采用其自身世界坐标方向。
4. 杂线与噪点：纹理图集中周期接缝产生错误mipmap采样，改为连续镜像取样；关闭过强法线纹理、减少地面噪声、去掉贴地重复网格，提高近裁剪距离。食品启用mipmap和干净的透明边缘，离线高清图集1024方形，低档保留1024×768共享预览。物品在自身实际占位内随视角显示，取消人为加高和过量倾斜，俯视仍可见。
5. 冰箱：原始远景简化网格背板本身有洞，旧层板改写又按三角形删除柜体表面。改为识别完整独立旧层板，补齐连续背板/侧板/顶板/底板，清除损坏壳体、旧抽屉与新首层冲突，柜门限制在柜体高度和地面之上。保留原来的门、把手、密封条、灯和温控。

额外修复：低档物资栏的缩略图曾沿用旧图册坐标，高清图集变形后SVG默认等比导致空白/串图；改为各自的真实裁切坐标。
